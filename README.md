# SmartVisit V2.1 — 애니존 / 기본 전화 앱 연동 시도용 안드로이드 소스

**현재 상태: APK 자동 빌드 워크플로와 Android Studio 소스 작성. 이 환경에서 APK 미빌드, 갤럭시 실기기 테스트 미검증.**

## 바로잡은 핵심 요구사항

외근프로는 **애니존에서 고객번호를 선택**하고 갤럭시 **기본 전화 앱으로 통화**합니다. SmartVisit을 열어 번호를 입력하거나 SmartVisit에서 전화를 거는 과정은 **없습니다**. 통화 종료 후 고객에게 SmartThings 안내 이미지를 보낼지 사용자가 선택합니다.

1. 설치 후 소속·이름과 ON/OFF, 중복 발송 주의 기간을 설정합니다.
2. 사용자가 `통화 식별 역할` 및 통화 상태·알림 권한을 허용합니다. 이 역할은 기본 전화 앱을 교체하지 않지만 다른 스팸/발신자 식별 앱과 충돌할 수 있습니다.
3. 평소처럼 애니존에서 고객번호를 눌러 통화합니다.
4. Android `CallScreeningService`가 **발신** 통화의 전화번호를 제공하는 경우에만 해당 번호를 저장합니다.
5. 전화 상태 `OFFHOOK → IDLE`을 감지하면 알림을 게시합니다. 다만 이 변화로 통화 상대가 실제로 받았는지를 알 수는 없습니다.
6. 알림을 눌러 개인화 이미지를 미리 보고, 고객번호를 확인한 후 `보내기 / 보내지 않기`를 선택합니다.
7. 보내기를 선택하면 기본 문자 앱에 MMS 이미지 공유를 시도합니다. 갤럭시 메시지 앱의 수신번호 자동 지정·이미지 첨부 작동은 실기기 검증 전까지 보장하지 않습니다. **문자 앱에서 실제 발송을 한 번 더 확인**해야 합니다.
8. 발송 이력의 `사용자 발송 확인`은 **외근프로의 수동 확인**, 통신사 전송 완료 확인이 아닙니다.

## V1 → V2 주요 변경

- **삭제:** 앱 내부 고객번호 입력 후 전화 걸기(`ACTION_DIAL`) 및 발신 관련 버튼
- **추가:** `OutgoingCallScreeningService` + `RoleManager.ROLE_CALL_SCREENING` 허용 화면
- **변경:** 시스템 통화 식별로 확보한 발신번호 + 기존 `PHONE_STATE` 수신기 연계
- **유지:** 소속·이름 합성, MMS 앱으로 공유, 사용자 전송·취소, 중복 발송 경고, ON/OFF, 발송 선택 이력
- **별도:** 예외 상황에만 쓰는 수동 번호입력 기능(전화 걸기가 아님)

## 기술적 제한과 위험 (확인 필요)

- 애니존 연동 API 없이 통화가 **애니존에서 시작됐는지 식별 불가**. 통화 식별 역할이 활성화된 상태의 다른 발신 통화도 알림 후보가 됩니다. 개인통화는 보내지 않기로 취소하세요.
- `CallScreeningService`는 기본 전화 앱을 바꾸지 않지만 사용자에게 **발신자 ID/통화 스크리닝 역할 승인**을 요청합니다. 기기·OS가 허용하지 않거나 해당 역할이 다른 앱에 할당된 경우 감지가 되지 않을 수 있습니다.
- Android 공식 문서는 **연락처에 저장된 번호**의 경우 `READ_CONTACTS`가 없으면 CallScreeningService에 제공되지 않을 수 있다고 설명합니다. V2.1에서는 선택적 연락처 권한을 별도로 요청할 수 있습니다. 허용하지 않으면 저장된 연락처 번호를 감지하지 못할 수 있습니다.
- 갤럭시의 절전 정책, Android 버전, SIM 구성 등에 따라 전화 종료 수신기·알림이 동작하지 않을 수 있습니다.
- `OFFHOOK`은 통화 연결의 증명이 아니므로 **부재중/통화 실패도 후보 알림이 나올 수 있습니다**.
- Android 10 이상에서는 다른 앱이 백그라운드에서 화면을 강제로 열기 어렵기 때문에 **알림을 눌러 미리보기 화면으로 이동**하도록 했습니다.
- 앱이 통신사 MMS 발송 성공, 고객 수신 여부를 자동 확인하지 않습니다.
- 이미지·고객번호의 개인 정보와 회사 업무정책, 메시지 발송 비용은 실제 배포 전 반드시 확인해야 합니다.

## 프로젝트

- Android Java, 최소 Android 10(API 29), Android Gradle Plugin 8.7.3, compileSdk 35, Java 17.
- 소스: `app/src/main/java/kr/co/namulsan/smartvisit/`
- 화면 시연: `demo/SmartVisit_V2_통화감지_시연.html`
- 이미지 템플릿: `app/src/main/assets/guide_blank.png` (941x1278). 사용자의 이름·소속 합성용.
- 시연 HTML은 실제 통화 감지/MMS 발송 기능이 없는 **화면 전용** 파일입니다.
- 기존 V1의 잘못된 전화 걸기 중심 HTML은 이 버전에서 사용하지 않습니다. 가상 통화 시연에는 번호 입력칸이 없습니다.

## 빌드 방법과 검증 구분

1. Android Studio에서 프로젝트 폴더를 엽니다.
2. SDK 35 / Java 17 / Android Gradle Plugin 8.7.3 / Gradle 8.9를 준비합니다.
3. Gradle Wrapper는 포함하지 않았습니다. Android Studio에서 정상 Wrapper를 생성하거나 Gradle 8.9를 지정하세요. GitHub Actions 자동 빌드 설정도 동봉했습니다.
4. 동기화 후 `Build APK(s)`를 실행합니다.
5. 갤럭시 실기기에서 **애니존 발신 → 기본 전화 앱 → 발신번호 감지 → 통화 종료 알림 → MMS** 순으로 테스트합니다.

**현재 이 실행 환경에는 Android SDK/Gradle이 없어 APK 컴파일이나 통화 실기기 검증을 수행하지 못했습니다. Java 구문 분석, 정적 조건 검사, HTML 문법 검사만 별도로 진행할 수 있습니다.**


## V2.1 추가 사항
- 앱 내부 전화 걸기 또는 수동 번호 발신 화면 없음: 모든 일반 발신 통화 감지 시도.
- 앱 최초 활성화는 OFF: 외근프로가 소속·이름을 설정한 후 ON으로 변경.
- 연락처에 저장된 전화번호 감지 지원용 `READ_CONTACTS`는 사용자가 **선택적으로** 허용. 목록을 앱에서 조회하거나 저장하지 않음.
- 통화 종료 신호가 통화번호 식별보다 먼저 도달하는 경우의 경합을 일부 보완.
- `.github/workflows/build-apk.yml` 추가: GitHub Actions에서 디버그 APK 자동 빌드 가능하도록 구성(워크플로 실행 미검증).
- `BUILD_APK_안내.txt` 참조.
