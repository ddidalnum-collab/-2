# SmartVisit V4 — 화면 캡처 허용 + 외근프로 사진 합성

이 프로젝트는 사용자가 테스트한 **SmartVisit V3** 기반의 수정 소스입니다. V3의 통화 감지·자동 팝업·사용자 보내기 선택·직접 MMS 전송 요청 코드는 유지했습니다.

## V4 변경 사항

1. **화면 캡처 허용**
   - `CallMonitorService.java`의 화면 위 팝업에 있던 `WindowManager.LayoutParams.FLAG_SECURE` 제거.
   - SmartVisit이 만든 팝업/앱 화면의 캡처를 금지하지 않습니다. 단, **화면 뒤에 있는 다른 앱 자체가 캡처를 막는 경우**까지 무효화하지는 못합니다.
2. **개인 프로필 사진 등록**
   - 앱 첫 화면에서 **사진 선택·변경 / 사진 삭제**를 사용할 수 있습니다.
   - Android 시스템 파일 선택기(`ACTION_OPEN_DOCUMENT`)에서 이미지 파일을 선택하고, 앱 내부 저장소에 크기를 줄여 보관합니다. 사진 전체 갤러리 접근 권한은 요청하지 않습니다.
   - EXIF 방향을 읽고 정방향 저장을 시도하며 원본 사진은 수정하지 않습니다.
3. **고객 안내 이미지 개인화**
   - 안내 이미지 *오른쪽 하단 흰색 카드*에 **왼쪽: 선택한 사진 / 오른쪽 위: 소속 / 오른쪽 아래: 이름 + 프로** 순서로 합성합니다.
   - 사진이 등록되지 않았다면 V3의 소속·이름만 표시하는 레이아웃을 유지합니다.
   - 실제 MMS로 보낼 JPEG 파일과 **미리보기**가 같은 `MessageImageComposer`를 사용합니다.
   - 사진 추가로 이미지 크기가 늘 수 있어 JPEG 품질을 단계적으로 낮춰 1MB 안으로 저장하도록 구현했습니다.
4. `versionCode=5`, `versionName=0.5.0-PHOTO-SCREENSHOT-TRIAL`.

## 확인된 항목 / 아직 확인되지 않은 항목

- **확인:** 16개 Java 파일 구문 파싱, AndroidManifest XML, 이미지 템플릿 941×1278, 사진 선택/저장/합성 호출 연결, 팝업 `FLAG_SECURE` 제거, ZIP 무결성.
- **미확인:** Gradle/Android SDK 기반 APK 컴파일, 갤럭시에서 사진 선택기 작동, 화면 캡처, 실제 통화 종료, 이동통신사 MMS 전송 및 수신. 소스 작성이 APK 정상 동작을 의미하지 않습니다.
- 기존 V3에서 발생한 **SMS 접근 권한 차단은 이번 두 가지 수정으로 해결되지 않습니다.** 안드로이드 권한과 통신사 전송 테스트를 별도로 다뤄야 합니다.
- 기존 통화 감지 및 MMS 전송 흐름은 유지했지만, 사용자의 기기에서 정상 동작한다는 보장은 없습니다.

## GitHub 빌드 방법

1. 기존 `ddidalnum-collab/-2` 저장소에 V4 프로젝트의 **내용물**(`.github`, `app`, `demo`, `tests`, `build.gradle`, `settings.gradle`, `gradle.properties`, `README.md`, `BUILD_APK_안내.txt`)을 저장소 최상위 기준으로 반영하세요. 바깥 폴더 자체를 한 단계 더 넣으면 빌드가 실패합니다.
2. `.github/workflows/build-apk.yml`이 V4의 워크플로로 교체됐는지 확인하세요.
3. GitHub **Actions → Build SmartVisit Debug APK** 실행 결과를 확인한 후 성공한 작업의 **Artifacts → SmartVisit-V4-photo-screenshot-test-APK**를 받으세요.
4. APK를 설치한 다음 본인 소유 시험 번호로만 문자 흐름을 확인하고, 사진 등록→미리보기→팝업 화면 캡처를 검증하세요.

> GitHub 웹 업로드에서 **동일 경로 파일 자동 덮어쓰기**가 지원되지 않거나 충돌하면, 저장소 파일 내용을 편집하거나 GitHub Desktop/Git으로 변경 사항을 커밋해야 합니다. 프로젝트 전체를 삭제할 필요는 없습니다.

## 사진 사용 시 참고

- 정면 얼굴과 어깨가 보이는 세로형 사진 권장. MMS로 전송하면 사진도 고객에게 전달됩니다.
- 선택한 사진은 앱 내부 저장소에 저장합니다. **앱을 삭제하면 해당 앱 사진도 삭제될 수 있습니다.**
- 사진을 변경하거나 삭제한 후, **사진 · 소속 · 이름 적용 미리보기**에서 결과를 확인하세요.
